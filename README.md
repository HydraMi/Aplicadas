# 🧠 Matemáticas Aplicadas 
# Universidad Icesi

Este repositorio contiene materiales, códigos en Python (Colab), ejercicios resueltos y explicaciones detalladas de los cursos de Matemáticas Aplicadas I y II cursados en el programa de Ingeniería en la Universidad Icesi. 
> 🎯 Enfoque práctico con visualizaciones y simulaciones usando Python y Google Colab.

---

## 📘 Aplicadas I

- Derivadas e interpretación geométrica
- Límites y continuidad
- Reglas de derivación (producto, cadena, etc.)
- Modelos y problemas en una variable
- Visualización de funciones con Python
- Uso de SymPy y Matplotlib

---

## 📗 Aplicadas II

- Técnicas de integración
- Ecuaciones diferenciales separables
- Álgebra matricial y funciones multivariables
- Derivadas parciales, gradiente, plano tangente
- Optimización en varias variables
- Visualizaciones en 2D y 3D con Python
- Simulaciones de problemas reales

---

## 📙 Matemáticas Aplicadas III

Curso enfocado en la **modelación y resolución de problemas de ingeniería y ciencias** usando **álgebra lineal** y **cálculo con campos escalares y vectoriales**, apoyado fuertemente en herramientas computacionales.

### 🔹 Temas principales

### 🧮 Integración en varias variables
- Integrales dobles y triples  
- Integración de campos escalares y vectoriales  
- Interpretación geométrica  
- Estimación de áreas y volúmenes  
- Superficies parametrizadas  

### 📐 Álgebra lineal aplicada
- Subespacios y complementos ortogonales  
- Transformaciones lineales  
- Sistemas lineales y problemas inversos  
- Valores y vectores propios  

### 📊 Mínimos cuadrados
- Sistemas sin solución exacta  
- Proyección ortogonal  
- Optimización por mínimos cuadrados  
- Aplicaciones en ciencia e ingeniería  

### 🖥 Enfoque computacional
- Simulación y análisis con Python  
- Uso de Google Colab como herramienta central  
- Apoyo con software como **GeoGebra**  

## 🛠 Herramientas

- Google Colab  
- Python (NumPy, SymPy, Matplotlib)
- Cuadernos Colab oficiales de la Universidad
- GeoGebra (apoyo visual)
