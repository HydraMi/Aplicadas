# 🧠 Matemáticas Aplicadas 
# Universidad Icesi

Este repositorio contiene materiales, códigos en Python (Colab), ejercicios resueltos y explicaciones detalladas de los cursos de Matemáticas Aplicadas I y II cursados en el programa de Ingeniería en la Universidad Icesi. 
> 🎯 Enfoque práctico con visualizaciones y simulaciones usando Python y Google Colab.

---

## 📘 Aplicadas I

- Derivadas e interpretación geométrica
- Límites y continuidad
- Reglas de derivación (producto, cadena, etc.)
- Modelos y problemas en una variable
- Visualización de funciones con Python
- Uso de SymPy y Matplotlib

---

## 📗 Aplicadas II

- Técnicas de integración
- Ecuaciones diferenciales separables
- Álgebra matricial y funciones multivariables
- Derivadas parciales, gradiente, plano tangente
- Optimización en varias variables
- Visualizaciones en 2D y 3D con Python
- Simulaciones de problemas reales

---

## 🛠 Herramientas

- Google Colab  
- Python (NumPy, SymPy, Matplotlib)
- Cuadernos Colab oficiales de la Universidad
